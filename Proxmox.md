Proxmox Virtual Environment (Proxmox VE) is an open-source virtualization platform based on Debian GNU/Linux. It lets users run full virtualization with dedicated hardware or OS-level virtualization. I will use it not just as a hypervisor, but as a software-defined datacenter framework that unifies compute, storage, and networking across physical sites.

In Proxmox, a bridge is a software-based virtual switch that uses network interfaces in place of physical cables.
